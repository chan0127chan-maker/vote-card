# Vote Card · 1128 我會去投票

以石虎、水牛、臺灣藍鵲的亮色手繪封面，將生活裡的詞聚焦成一件關心的事。此為獨立的Vote Card原始碼專案。

上傳與新環境操作請先看 [GITHUB.md](GITHUB.md)，素材註記見 [SOURCES.md](SOURCES.md)。需要Python 3.10以上，無第三方Python套件或前端建置步驟；本包不含本機資料庫、管理帳密與私人信件。

## 啟動

```sh
python3 -m server.app --port 4174
```

[玩家頁](http://127.0.0.1:4174/) · [內容後台](http://127.0.0.1:4174/admin/)

只綁定本機，尚未部署；本機連結無法供其他裝置或社群平台讀取。

## 玩家操作

拿筆搖動或按「浮現」，先遇到生活願望，再想起關心的人。可以持續抽詞、拖曳、拆合及剔除；畫面騰出空間後可繼續抽詞。第一版同時最多八個詞件，最多256字。

保留的完整詞片段帶出需求、年齡、身份或情境編碼，政策會即時聚焦到畫布中的政策區；不另外要求選議題。候選人預設全部呈現，可改為部分摘錄，尚未收錄者的狀態也保留。來源與資料日期直接可讀。

沒有自由補字，橫線只留下最多12字的可選署名。保留郵戳鎖版、解鎖、教學、翻面。封面可翻看或單獨下載。

先選「Facebook 橫式 1200×630」或「限時動態 9:16」。選擇的是創作畫布本身，並非最後裁切；下載分別為1200×630與1080×1920。兩版各自安排字句與政策區。沿用畫面字句位置、字級、換行與色塊；筆和操作按鈕不進圖片。傳送訊息會保存比例與唯讀信件，閱讀半年；保存後點郵戳才能繼續修改。

## 苗栗內容與後台

目前88個生活片段、14個聚焦議題，納入來源頁的托育、運輸、校園、動保、觀光、文化等類別。生活願望、對象、情感／情境交替出現。學校餐食與工作生計是具體項目未收錄的示範，沒有補造政見。來源入口：https://blindvote.app/sources/miaoli 。完整摘要、最多26字的圖面短句與創作詞句分開；資料日期採來源個別頁標示的2026-10-18。不將未收錄等同未提出。部分原始貼文無法直接讀取，保留來源頁連結並標明據留白投票所收錄。

後台首次自行設定12–200字元管理密碼，沒有預設帳密。表格維護生活詞句、政策編碼、議題與政見、候選人及原始來源；儲存草稿、發布、修訂紀錄、還原草稿分開操作。發布不改動已寄出信件的政策快照。

`content/site.json` 僅首次初始化。之後請從後台維護，資料存於獨立 `.data/letters.sqlite`；沒有複製木字帳密或資料庫。舊 `content/catalog.json` 不是目前的初始化來源。

詳見 [實作與 API 說明](IMPLEMENTATION.md)。

## 驗證

```sh
node --test demo/*.test.mjs
python3 -m unittest discover -s tests -v
```

90項前端與8項後端測試，另有桌面／手機的瀏覽器操作驗證。正式後台密碼由使用者設定；登入與發布測試使用隔離的暫存資料庫。素材升級會先備份 `.data/` 資料庫，保留既有登入、舊信及草稿／發布隔離。
